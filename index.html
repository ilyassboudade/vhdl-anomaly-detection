Context

Traditional VHDL compilers and linters are limited to basic syntax checking and frequently fail to detect subtle logical or semantic anomalies prior to active functional simulation.
This project leverages a Recurrent Neural Network (RNN) (a sequential deep machine learning algorithm) to automatically identify failing structural behaviors and semantic flaws in hardware code, and to challenge the limits of a Recurrent Neural Network on tasks that have bigger requirements than its capabilities.

Model Architecture

Guaranteeing total mastery over temporal backpropagation dynamics, the RNN was implemented entirely from scratch with NumPy and Pandas.

Sequence 512 Tokens (Max Size)
Embedding 64 Dimension Vector
Hidden State 128 Neurons (Single RNN Layer Size)
Optimization Adam
Learning Rate: 3 × 10-3
Gradient Clip: 5.0

Dataset Profile

8,613
Balanced Dataset (50 / 50) cleaned from a standardized Hugging Face repository
  • Healthy Code clean excerpts 4,307 · 50.0%
  • Dead Code Injection inaccessible / useless code 1,154 · 13.4%
  • Syntax Corruption missing semicolons, keyword swaps 1,126 · 13.1%
  • Structural Havoc destroyed syntax structure 1,079 · 12.5%
  • Scramble Architecture shuffled logic blocks 947 · 11.0%

Because real defective VHDL code is scarce, a custom error-injection pipeline corrupted the healthy excerpts to reach a perfect 50/50 balance — giving the RNN equal exposure to normal and anomalous structures.

Detection Profile

78.4%
Global Test Accuracy after 15 epochs — rapid convergence by epoch 6
Syntax Errors ~80% sensitivity
Semantic Errors ~55–60% sensitivity
False Positives 21% rate

The model reliably detects grammatical breaks and keyword corruptions, and moderately detects logical flaws and structural chaos; however, due to memory loss on long sequences, it occasionally flags healthy excerpts as anomalous.
