Model Architecture & Sequence Limits

The core neural detector utilizes a recurrent sequence architecture designed specifically for structural token analysis:

  • Limit 512 Tokens maximum sequence window per RNN chunk[cite: 1, 2].
  • Embedding 64-dimensional token vector space[cite: 3].
  • Hidden State 128 hidden units (Single-layer RNN)[cite: 3].
  • Vocabulary 76,205 unique structural VHDL tokens[cite: 3].

Sensitivity & Detection Profile

The anomaly inspector evaluates VHDL structural syntax and logical consistency across two distinct fault categories:

  • Syntax Errors: ~80% Sensitivity[cite: 1, 2]. Flags structural deformities, missing semicolons, unmatched delimiters, and malformed entity/port declarations.
  • Semantic Errors: ~55–60% Sensitivity[cite: 1, 2]. Identifies contextual mismatches, logic operator substitutions (e.g., AND/OR swaps), and undeclared signal assignments.

This inspector recognizes three validated reference vectors carried over from the training notebook and returns their exact recorded probabilities on an exact match. For any other input, the trained RNN itself isn't embedded here — its learned weights were never exported from the training session, only the vocabulary and datasets were — so a lightweight rule-based heuristic estimates a plausible score by checking for missing semicolons, unbalanced structure, and operator/name mismatches instead. Treat heuristic results as illustrative, not as real model output.
